# Ferry 主题图标

定稿为 FE 船舱、rry 水波和细线挡风玻璃的组合。两套配色保持同一构图，琥珀黄烟囱保留。

| 主题 | 底色 | 图形 | 母版 |
| --- | --- | --- | --- |
| 浅色 | 米白 | 深蓝 | `ferry-light.png` |
| 深色 | 深蓝 | 米白 | `ferry-dark.png` |

母版为 1024 × 1024 PNG，外侧圆角透明，底色内部不透明；`theme-preview.png` 是并排预览，`ferry-approved.png` 保留用户确认的原稿。设计通过内置 image_gen 编辑完成，最终使用的提示词在 `generation.json` 中。

界面使用 `desktop/public/branding/` 下的 256px 版本。`FerryLogo.vue` 复用于主导航和关于页，直接跟随根元素的 `dark` 状态，切换时不需要重新加载图片。`theme-init.js` 在首次绘制前读取上次主题并同步 favicon，`applyTheme` 负责手动切换、设置预览及跟随系统。原生窗口图标由 `appIcon.ts` 同步更新，下载结果缓存，窗口更新串行执行，避免快速切换时出现旧主题覆盖新主题。

`desktop/app-icon.png` 是默认深色图标源，`src-tauri/icons/` 的 Windows/macOS 安装资源由 Tauri icon 命令生成。`icons/themes/` 下的两套 ICO 编译进 Windows 程序，运行时按主题导出到 `%LOCALAPPDATA%/Ferry/icons/<应用标识>/`；文件名包含资源指纹，深浅主题和后续设计修订不会覆盖同一个缓存路径。安装程序自身仍使用默认图标。

Windows 的 `sync_shell_icon` 命令仅允许主界面调用，主题参数为布尔值，不接收任意目标路径。它同步运行窗口的任务栏分组图标，并查找桌面、开始菜单和固定任务栏目录中的现有快捷方式；只更新目标完整路径与当前 Ferry 程序一致的链接，保留参数、工作目录和应用标识，不新建固定项。保存后使用 Shell 图标通知刷新对应缓存。

Windows 合并任务栏按钮会保留已显示分组的图标，仅更新 `WM_SETICON`、窗口属性和快捷方式不足以刷新这个按钮，要用 `ITaskbarList::DeleteTab` / `AddTab` 重建当前窗口的任务栏项；窗口和进程保持运行，不重启 Explorer，也不修改固定记录。实测（逐帧截任务栏按钮）要点：

- 顺序：先存快捷方式，再改窗口属性和窗口图标（前端先调 `sync_shell_icon` 再 `setIcon`）。任务栏看到窗口变了会重新取并记下分组图标，快捷方式还没改好就记成旧的，之后一直显示旧图标。
- 通知 Shell 时 `SHUpdateImage` 传换之前的图标；快捷方式正被资源管理器或索引读取时保存会失败（0x800704C8），稍等重试。
- 改完等 2.5 秒、只重建一次（按钮只闪一下）；删掉后隔 0.6 秒再加回，马上加回会接着用正在消失的旧按钮。等 1.5 秒约 3% 停在旧图标，2.5 秒 60 次全对。
- 快速连着切换时只由最后一次重建，重建之间互斥，最终是最后选的主题。

启动时窗口还没显示则跳过重建，避免提前出现任务栏按钮；后台窗口不会被激活。手动主题预览、取消预览、跟随系统和启动恢复都会走同一条更新队列。

标题栏左上角的图标和文字在 Windows 上隐藏，任务栏图标继续随主题更新。Tauri 启用了 `image-png` 和仅针对主窗口的 `core:window:allow-set-icon` 权限。Ferry 关闭期间不会监听系统主题；重新打开后会按当前主题同步。

验证：前端构建、图标异步切换和故障重试测试、设置保存回归、Windows 快捷方式保留参数及精确目标匹配测试、任务栏窗口属性测试，以及浅色/深色/跟随系统和重启恢复主题的浏览器检查。
