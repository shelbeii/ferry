# 页面交互排查记录

日期：2026-11-03。范围为桌面端页面、弹窗、抽屉及它们使用的全局状态、命令调用和异步回调。

本轮采用代码审查、自动化回归测试和真实 Vue 组件配合模拟后端的浏览器验证。构建检查覆盖目前 58 个 Vue 组件；不等于逐一在真实服务器上点过所有按钮，也不保证所有环境中都没有缺陷。

## 已确认并修复的问题

| 优先级 | 场景与原问题 | 修复后的行为 | 主要位置 |
| --- | --- | --- | --- |
| P1 | 启停应用、改端口、断开 SSH 会话等操作，在确认之后才读取当前连接；等待确认时目标变化会导致操作错位 | 捕获目标和页面版本，确认后再次检查；切换再切回也不能复用旧确认 | ProjectView、PortPanel、SshPanel、interactionScope |
| P1 | 软件升级、卸载、备份、密码窗口及展开的菜单可能沿用上一台服务器的数据 | 切换连接清理旧弹窗与菜单；迟到的密码/备份结果不写入新页面；等待确认期间切换则不发出操作 | SoftwarePanel、SoftwareConfigDialog、ProjectView |
| P1 | 部署审阅依赖主页面当前勾选，勾选清空或切换服务器可能改变待部署范围 | 打开审阅时保存应用和目标快照，审阅与执行使用这份快照 | ProjectView、DeployDialog |
| P1 | 配置编辑器保存前不检查文件是否已被运行环境切换等其他操作修改 | 保存前重新读取并比较；冲突时保留草稿并拒绝覆盖 | ConfigEditor、editor/saveDraft |
| P1 | 保存期间的新输入可能被当作已写入；配置超过在线校验上限时也可能被当成校验通过 | 只更新实际写入的保存基线；新输入保持未保存，不自动部署；较大配置保存后按磁盘文件完整校验 | ConfigEditor |
| P1 | 并发任务需要密码、公钥核对或处理占用文件时，共用单个请求引用，后到请求会覆盖先到请求 | 请求排队，各自保留配置、目标与重试回调；相同的待处理认证合并询问并重试所有相关任务；认证完成后再次失败使用新弹窗 | requestQueue、state、App、SecretDialog、TrustDialog |
| P2 | 软件 upgrade、restore、backup 等命令的任务目标识别错误，可能把子命令显示为服务器并用错认证重试目标 | 统一解析任务和认证的目标，覆盖软件配置子命令、端口测试、文件及多目标命令 | commandContext、state |
| P2 | 部分详情窗口没有读取上限，关闭后请求仍等待；刷新日志还可能等待上一次取消收尾 | 详情、运行环境候选、版本、历史、部署比较、文件列表/预览、软件日志、备份状态、公钥、端口测试等使用有上限的读取；组件销毁自动取消。应用日志首次读取有 60 秒上限，正常开始持续接收后不限制总时长 | readRequests 与各读取窗口、LogsDialog |
| P2 | 软件安装方式切换后，上一种方式的版本查询可能覆盖当前选择；新建项目的目录识别、文件存在检查和服务器探测也有迟到结果覆盖问题 | 按请求序号和输入快照接收结果，取消/忽略过期请求 | InstallSoftwareDialog、NewProjectDialog |
| P2 | 文件夹命名、改名、删除确认期间若目录变化，旧文件名可能和新目录组合 | 对照发起时的目录；目录变化就不执行尚未提交的操作 | FilePanel |
| P2 | 切换预览文件时保存/对比状态可能残留 | 读取上下文切换时重置保存和对比状态，保留原有版本校验与未保存提示 | FilePreviewDialog |
| P2 | AI 图片处理结果、认证重试和安全输入可能跨到新对话；导出选择路径后可能改用新会话 ID | 按会话版本接收图片和重试；新建对话清理安全输入；导出捕获发起时的会话 ID | AiDrawer |
| P2 | 设置里的模型/通知测试结果可能在编辑内容或对象变化后仍显示为当前结果 | 编辑变化立即使旧测试结果失效，迟到结果不再覆盖 | AiModels、NotifyChannels |
| P2 | 保存设置/连接期间可重复提交或关闭，后续写入与页面状态可能分离 | 增加保存重入与关闭保护；连接密码使用提交时的快照 | SettingsDialog、ConnectionDialog、SecretDialog、TrustDialog |
| P1 | 设置与模型、通知、DNS 凭据分步骤保存，中途失败会部分生效，草稿也可能提前清空 | 一次提交整批变更，全部校验后在内存中备份旧凭据；凭据、索引或设置文件写入失败逆序恢复，明确报告恢复失败；成功才清空草稿和更新缓存。保存期间锁定编辑，导航保存排队并使用最新设置 | SettingsDialog、settingsSecrets、state、settings/transaction、secret/transaction |
| P2 | MCP 调用列表的搜索定时器和读取可在销毁后继续；终端关闭确认期间标签已被移除时，负索引可能误删最后一项 | 销毁时清理定时器/请求；删除标签前重新确认它仍在列表中 | McpCallsDialog、ConnectionView |
| P2 | 从保留的运行详情跳回另一台连接的版本或文件位置，可能被连接切换的清理逻辑立即清空 | 先完成目标切换，再打开对应窗口；详情/环境窗口按应用和服务器区分实例 | ProjectView |

浏览器使用真实 SshPanel、PortPanel、SoftwarePanel、SecretDialog，替换命令调用为模拟后端：

- 162 的 SSH 断开确认期间切到 41，再确认：未发出断开命令。
- 162 的端口关闭确认期间切到 41，再确认：未发出端口修改命令。
- 已打开软件卸载窗口后切到 41：窗口关闭，未发出卸载命令。
- 162、41 同时需要密码：依次显示并各自重试，没有互相覆盖。
- 真实 SettingsDialog 与 DNS 表单配合模拟后端：后一个服务商缺 ID 时未发送任何保存；补全后模拟提交失败，整批输入仍保留；直接重试成功后关闭窗口，仅成功一次。

## 尚需注意的边界

- 设置与凭据使用普通错误下的补偿回滚；不将凭据旧值写入明文事务日志。进程崩溃、断电，以及外部程序并发改写系统凭据库不具备跨库原子保证。
- 本轮没有对真实服务器执行启停、卸载、恢复、删除、部署或通知发送，也未验证各发行版、各软件版本的真实执行结果。
- 浏览器模拟不代替 Tauri 安装版、系统文件选择器、凭据库和网络断线的实机验证。界面超时解决等待状态，不能据此认定底层 SSH 网络迟滞已被修复。
- 代码和前端构建已更新；安装版需重新打包更新后才能使用这些改动。
